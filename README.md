# 📈 長期投資向け銘柄情報自動取得ツール (Stock Fetcher)

指定した企業（日本株）の長期投資に必要な主要財務・株価指標を Yahoo Finance から自動取得し、ローカル環境で直接CSVファイルに出力・保存するデスクトップアプリケーションです。
IT知識がないユーザーでも、ダブルクリックだけで直感的に操作できるように設計されています。

---

## ✨ 主な特徴

- **1ファイルで完結**: PythonやDockerの環境構築が不要な単一実行ファイル（`.exe`）。
- **洗練されたWeb UI**: HTML/JS/CSSによる直感的な操作画面。
- **高速な起動とバックグラウンド同期**: 
  - 起動時は常にローカルのキャッシュ（`data/master_tickers.json`）を優先して読み込み、0.1秒で即座にUIへ反映。
  - JPX（日本取引所グループ）からの最新銘柄マスター取得は、前回の更新から30日以上経過している場合（月1回）またはUI上の手動更新ボタンが押された場合のみ、バックグラウンド非同期処理で自動実施。
  - 将来の多国株対応を見据え、マスターデータは名前空間化されたJSON構造で保持。
- **効率的なピンポイントデータ取得**:
  - 財務・株価データは全件一括取得を行わず、UI上で「選択された銘柄」「選択された指標」のみを対象に `yfinance` から都度取得。
  - 特に処理負荷の大きい自己資本比率（`equity_ratio`）が未選択の場合は、バランスシートのダウンロードと計算を完全にスキップして高速化。
  - 万が一、取得不能な指標データ（`None` / 空値）が存在しても処理を中断せず、`N/A` で補完してCSV書き出しを完了。
- **設定およびキャッシュの自動保持・復元**:
  - 選択した「商品区分」「出力項目」「選択銘柄」「CSV保存先パス」は自動的に `data/user_config.json` に保存され、次回起動時に完全に復元。
- **ローカル直接出力のシンプルUI**:
  - 出力処理は「CSVデータを出力・保存」ボタン1つに集約。エクスプローラーダイアログに依存しない、直接パス指定による確実な書き出し。
  - 完了時はメッセージのみをシンプルに表示。

## 🛠 技術スタック

- **パッケージ管理**: `uv`
- **バックエンド**: Python 3.10+, FastAPI, Uvicorn
- **デスクトップ化**: PyInstaller, PyWebView
- **フロントエンド**: HTML5, Vanilla JS, Tailwind CSS
- **データ取得**: `yfinance`, `pandas`, `openpyxl`
- **タスク自動化**: `just`

## 🚀 開発・ビルド手順（開発者向け）

開発およびビルドの自動化には [`just`](https://github.com/casey/just) コマンドを使用します。

### 1. 開発環境のセットアップ

```bash
# リポジトリのクローン
git clone https://github.com/your-username/stock-fetcher.git
cd stock-fetcher

# uvによる仮想環境の構築と同期
uv sync
```

### 2. ローカル開発サーバーとアプリの起動

```bash
# アプリケーションの起動（開発モード）
just run
```
または手動で起動する場合:
```bash
uv run python -m app.main
```

### 3. 銘柄マスターの手動即時同期
```bash
# JPXから強制的に最新の銘柄マスターを同期
just update-master
```

### 4. 実行ファイルのビルド

```bash
# PyInstallerによるビルド実行（dist/StockFetcher.exe が生成されます）
just build
```
または手動でビルドする場合:
```bash
uv run python build.py
```

## 📁 ディレクトリ構成

```
INVESTMENT_DATA/
├── pyproject.toml         # uv 管理の依存関係定義
├── uv.lock                # バージョン固定用ロックファイル
├── justfile               # コマンド自動化タスク定義
├── build.py               # PyInstaller ビルドスクリプト
├── app/
│   ├── main.py            # FastAPI エントリーポイント & Web UI 起動
│   ├── updater.py         # 銘柄マスター非同期自動更新モジュール
│   ├── fetcher.py         # yfinance 指標ピンポイント取得・CSV保存モジュール
│   ├── static/
│   │   ├── app.ico        # アプリケーションアイコン（.exe埋め込み・ファビコン）
│   │   └── app.js         # フロントエンドロジック（UI制御・ポーリング）
│   └── templates/
│       └── index.html     # Web UI テンプレート
└── data/
    ├── master_tickers.json # 東証上場銘柄キャッシュ（名前空間化JSON）
    └── user_config.json   # ユーザー設定保存ファイル（前回状態保持）
```
